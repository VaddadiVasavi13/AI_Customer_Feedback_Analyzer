# AI Customer Feedback Analyzer

## 1. Project Overview

AI Customer Feedback Analyzer is a machine learning and generative AI based application that analyzes customer feedback.

The system identifies:

- Customer sentiment
- Prediction confidence
- Important feedback aspects
- Aspect-level sentiment
- Key issues
- Positive points
- Suggested business actions
- Suggested response to the customer

The application combines a machine learning sentiment classifier with aspect detection and Llama 3.1 through Ollama to generate detailed feedback insights.
